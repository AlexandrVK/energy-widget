# Энергия — виджет графика отключений для Николаева

Виджет Android с графиком отключений электроэнергии и аварийными отключениями по адресу.

**Проект заточен исключительно для города Николаева.** Адреса, очереди и отключения берутся только из официальных источников АТ «Миколаївобленерго» (Николаевская область, филиал Миколаївський РЕМ, город Николаев):

- график отключений по очередям и очереди по адресу: https://off.energy.mk.ua/
- аварийные отключения по адресу: https://www.energy.mk.ua/vidklyuchennya/

Проект не связан с АТ «Миколаївобленерго» и не является официальным. Данные могут отставать от сайта или быть неточными, поэтому при сомнениях проверяйте их на официальных страницах.

## Что умеет

- Циферблат на 24 часа с получасовыми зонами: зелёный — свет есть, жёлтый — возможно отключение, красный — отключение.
- Плашка ГАВ, если по очереди ГАВ дома сейчас отключение. Плашка СГАВ, если сейчас отключена любая очередь СГАВ.
- Алый баннер в центре, если по выбранному дому сейчас авария: причина и время окончания.
- Красная полоса внизу, если связь с сайтом не удалась: данные могут быть неактуальны.
- Виджет растягивается по ширине и высоте.
- Кнопка «Обновить» на виджете и время последнего обновления.
- Проверка обновлений приложения раз в сутки и установка новой версии из настроек.

## Настройки

Один экран:
- **Дом**: населённый пункт, улица и дом. Можно выбирать из списка или вводить название с поиском.
- **ГПВ и ГАВ** подставляются автоматически по выбранному дому. ГПВ можно поменять вручную.
- **СГАВ** не выбирается: это общая очередь, и плашка появляется, если отключена любая очередь СГАВ.
- **Интервал** обновления: 15, 30 или 60 минут.

## Сборка

При каждом push в ветку `main` GitHub Actions собирает APK. Его можно скачать из релиза `latest` или из артефакта `energy-widget` во вкладке Actions.

Для обновления приложения из самого приложения версия в релизе называется «build N», где N — номер сборки.
