# Энергия — виджет графика отключений

Виджет Android для графика отключений off.energy.mk.ua.

- Циферблат 24 часа, получасовые зоны: зелёный — свет есть, жёлтый — возможно отключение, красный — отключение.
- Шестерёнка (левый верхний угол) — настройки: ГПВ, ГАВ, СГАВ, периодичность (15/30/60 мин).
- Кнопка обновления (правый верхний угол) — принудительно загружает данные с сайта.
- Красная плашка ГАВ / СГАВ появляется, если по выбранному номеру сейчас отключение.
- Если связи с сайтом нет или данные устарели, внизу виджета появляется красная полоса с предупреждением.
- Виджет растягивается по ширине и высоте.
- Нажатие на циферблат в виджете открывает приложение, там нажатие на зону показывает время и статус.

Сборка: при каждом push в main GitHub Actions собирает APK. Его можно скачать из релиза `latest` или из артефакта `energy-widget` во вкладке Actions. Ручной запуск: Actions → Build APK → Run workflow.
